# point of the site is that someone who cannot afford a course can still learn

# never going to find this site is that mission working, not a leak from it.
#
# AI crawlers were already allowed by the wildcard group below — nothing was
# ever blocking them. The named group exists because "we never got round to
# denying it" and "we deliberately allow it" look identical in a robots.txt
# that only has a wildcard, and the second is what this is. It also survives
# someone later tightening the wildcard without thinking about AI access.
#
# A note on how robots.txt actually works, because it is a common trap: a
# crawler obeys the MOST SPECIFIC group matching its user-agent and ignores
# every other group, including the wildcard. So each named group must repeat
# its own Allow rule — a group listing user-agents with no rules would not
# inherit "Allow: /" from below, and the result would be undefined rather
# than permissive. Hence the explicit Allow in the group.
#
# Sitemap and Host are cross-group directives and apply regardless.
