Lessons in this path

  1. What is Cloud Computing? — IaaS/PaaS/SaaS, and why this course is itself a cloud example.
  2. Cloud Providers Overview — AWS, Azure, GCP — the same concepts, different names.
  3. Cloud Compute Basics — VMs, containers, instance types, and auto-scaling.
  4. Cloud Serverless Basics — Functions, triggers, and why 'serverless' still has servers underneath.
  5. Cloud Storage Basics — Buckets, objects, and why misconfigured storage is a top real-world breach cause.
  6. Cloud Databases Basics — Managed relational, NoSQL, and data warehouse services, and their security tradeoffs.
  7. Cloud Networking Basics — VPCs, security groups, and the instance metadata service, explained fully.
  8. Cloud Logging & Monitoring Basics — CloudTrail-style audit logs, and why they're not always enabled by default.
  9. Cloud Cost & Billing Security — Cryptomining abuse, billing alerts, and cost as an early compromise signal.
  10. Cloud Identity & Access Management — IAM roles, least privilege, and why leaked keys are a leading breach cause.
  11. Cloud Multi-Account Governance — Landing zones, account factories, and blast radius at the account level.
  12. The Shared Responsibility Model — Where the provider's job ends and yours begins.
  13. Cloud Security Careers & Certifications — AWS/Azure/GCP security certs, CCSK, and how to build real hands-on experience.
  14. Cloud Basics Hands-On Lab — A real free-tier account, start to finish — prep for Path 16's flAWS lab.
