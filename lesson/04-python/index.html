Lessons in this path

  1. What is programming? — Recipes for computers, in plain English.
  2. Variables & data types — Labelled boxes: strings, numbers, booleans.
  3. Dictionaries & sets — Labelled data, and automatic uniqueness for things like log IPs.
  4. Decisions with if/else — The logic behind every login check.
  5. Loops: repeat things — How tools try 10,000 passwords in seconds.
  6. Error handling & exceptions — try/except, and why a real scanner can't crash on the first timeout.
  7. Why Python for security — Readable, ubiquitous, batteries included.
  8. Your first Python program — Print, input, comments — the write-save-run cycle.
  9. String manipulation & regex — f-strings, and pattern matching for log analysis and input validation.
  10. Lists & functions — Wordlists and reusable code blocks.
  11. Working with files in Python — Reading wordlists, parsing logs, and writing results safely.
  12. Python modules & packages — pip, virtual environments, and organizing your own growing scripts.
  13. Build a password checker — Combine everything into a real tool.
  14. Object-oriented Python basics — Classes, objects, and why real tools bundle data with behavior.
  15. Writing Secure Python Code — eval(), shell=True, hardcoded secrets, and unsafe pickle.
  16. Where to go next — requests, socket, hashlib — and a mini port checker.
  17. Python, requests & APIs — GET/POST, JSON, headers, and a realistic header-checking script.
  18. Python for network scripting — Sockets, a simple port scanner, and DNS lookups from code.
  19. Python Security Libraries: An Overview — hashlib, bcrypt, scapy, Beautiful Soup, and paramiko, named and mapped.
  20. Automation for Security — Why scripting and automation are essential in security.
  21. Python Careers & Next Steps — Why Python fluency is assumed, and how to build a real portfolio.
  22. Security Scripting Lab — Turn Python into a real security tool.
