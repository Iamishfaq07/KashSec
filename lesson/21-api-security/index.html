Path 21: API Security — KashSec Academy

APIs are the real backend of almost every modern app — the OWASP API Top 10, BOLA/BFLA, JWT attacks, GraphQL security, and a hands-on capstone lab against a real vulnerable API.

Sub-lessons

  • 21.1 · Why API Security Matters — APIs are the real backend now — and where most real-world breaches actually happen.
  • 21.2 · What are APIs and why do they matter for security? — The contract behind almost everything modern software does.
  • 21.3 · OWASP API Top 10 (2023) — The shared checklist for API risk, ten categories at a glance.
  • 21.4 · Authentication & Authorization in APIs — Who are you vs. what are you allowed to do — the distinction that matters most.
  • 21.5 · Broken Authentication & JWT Attacks — alg:none, algorithm confusion, and weak secrets — how tokens get forged.
  • 21.6 · BOLA & BFLA — the two most common API authorization failures — Object-level and function-level authorization, the #1 real-world API risk.
  • 21.7 · Mass Assignment & Excessive Data Exposure — When the API accepts — or returns — more than it should.
  • 21.8 · Rate Limiting, Injection & Resource Abuse — SSRF, classic injection, and business-logic abuse when limits are missing.
  • 21.9 · REST vs GraphQL — security differences that matter — Same goals, different attack surface — one endpoint changes everything.
  • 21.10 · GraphQL Security — Introspection, nested queries, and field-level authorization.
  • 21.11 · How to actually test APIs — A battle-tested recon-to-report workflow for bug bounty and pentests.
  • 21.12 · API Security Capstone Lab — Put it all together against a real vulnerable API — crAPI, vAPI, or your own.
  • 21.13 · Your API Security Roadmap — Where to go next, and how to keep growing this specialisation.
