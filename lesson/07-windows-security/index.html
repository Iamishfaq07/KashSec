Lessons in this path

  1. Windows Fundamentals for Security — Architecture, the Registry, and services — Windows' equivalent of Path 03.
  2. Windows Security Settings — Defender, Firewall, Windows Update, UAC, and BitLocker.
  3. RDP & Remote Access Security — Why exposed RDP is a top ransomware entry point, and how to lock it down.
  4. Windows Event Viewer — Reading the Security log — Windows' equivalent of auth.log.
  5. Recognizing a Compromised Windows Machine — The practical signs to check across processes, accounts, and scheduled tasks.
  6. Windows User Accounts & UAC — Standard vs. admin, least privilege, and account auditing.
  7. Windows Active Directory: The Basics — Domains, Domain Controllers, Kerberos, and why AD is such a high-value target.
  8. Windows Group Policy Basics — How GPOs enforce settings domain-wide, and why misconfiguration is a real finding.
  9. Windows Command Line Basics — Command Prompt and PowerShell, and why attackers love the latter too.
  10. Windows Services & Task Manager, for Security — Why services are an attacker's favorite persistence mechanism, and how to audit them.
  11. Securing a Windows Machine — A complete, practical hardening checklist.
  12. Windows Backup & Recovery — File History, System Restore, and why neither one is a ransomware defense on its own.
  13. Windows Privilege Escalation: An Introduction — Vertical vs. horizontal escalation, and the named technique categories to recognize.
  14. Windows Security Lab — Hands-on on a real Windows VM, start to finish.
