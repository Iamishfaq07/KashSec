Path 03 went deep on Linux — this path does the same for Windows: architecture, the Registry, Event Viewer, PowerShell, and a full hardening checklist.

  2. Windows Security Settings — Defender, Firewall, Windows Update, UAC, and BitLocker.

  10. Windows Services & Task Manager, for Security — Why services are an attacker's favorite persistence mechanism, and how to audit them.
  11. Securing a Windows Machine — A complete, practical hardening checklist.
  12. Windows Backup & Recovery — File History, System Restore, and why neither one is a ransomware defense on its own.

  14. Windows Security Lab — Hands-on on a real Windows VM, start to finish.
