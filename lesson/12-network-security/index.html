Path 12: Network Security — KashSec Academy

Nmap, Wireshark, firewalls, VPNs, IDS/IPS, Wi-Fi attacks, MITM.

Level: Intermediate · 20 lessons · Free, no account needed.

Lessons in this path

  1. Why network security matters — Mapping, watching, filtering — the three activities.
  2. Scan networks with Nmap — The classic scanner, from -sV to NSE scripts.
  3. See traffic with Wireshark — Watch real packets flow — plus tcpdump.
  4. Network Forensics Basics — Reconstructing what happened from a captured .pcap file after the fact.
  5. ARP Spoofing, Hands-On — How a classic local-network MITM actually gets established.
  6. Firewalls, VPNs, proxies — The everyday defensive stack.
  7. VPN Protocols: A Deep Dive — OpenVPN, WireGuard, IPsec, and the real tradeoffs between them.
  8. Network Segmentation in Practice — Designing real segments around trust boundaries, not organizational convenience.
  9. IDS, IPS & SIEM — Modern detection: from Snort to SOC to SOAR.
  10. Network Security Monitoring Tools — Zeek, Suricata, and Security Onion, named and mapped.
  11. Network Access Control (NAC) — 802.1X and posture assessment — deciding whether a device joins at all.
  12. Wi-Fi security & attacks — WPA2/3, evil twin, handshake capture.
  13. Bluetooth & IoT Network Security — BlueBorne, and the Mirai botnet as the definitive default-credential case study.
  14. DNS Attacks, Hands-On — Cache poisoning, hijacking, DNSSEC, and DoH/DoT.
  15. Man-in-the-Middle — How MITMs work, and how HTTPS defeats them.
  16. DDoS Attacks & Mitigation — Volumetric, protocol, and application-layer attacks, and how real infrastructure absorbs them.
  17. Cloud Network Security — Security groups and Network ACLs — this path's concepts, reimplemented in the cloud.
  18. Your network-security path — Red, blue, or engineering — pick a track.
  19. Advanced Nmap Lab — Master network scanning like a professional.
  20. Advanced Wireshark Lab — Go deeper with packet analysis.
