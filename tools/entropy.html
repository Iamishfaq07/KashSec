Entropy Calculator

Shannon entropy of any text — a genuine static-analysis signal for spotting packed or encrypted data.

Entropy measures unpredictability, in bits. It is how you tell a random session token from a sequential ID, how packers and encryption announce themselves inside a binary, and how secret scanners decide that a long string in a repository is worth flagging.

How to use it

  1. Paste text or hex.
  2. Read the length and Shannon entropy.
  3. Compare a real random token against a word or a predictable pattern.

What to take away

Rough bands to carry in your head

English text sits near 4 bits per character. Base64 of random data approaches 6. Compressed or encrypted bytes approach 8 bits per byte, which is what makes high entropy suspicious inside an otherwise normal file.

High entropy is a hint, not a verdict

Secret scanners flag high-entropy strings and produce plenty of false positives on hashes, UUIDs and minified code. It narrows the search; it does not decide.

Low entropy in a token is a finding

A session identifier that is short, sequential or timestamp-derived can be guessed. Entropy is how you demonstrate that in a report.

Frequently asked questions

What is a good entropy for a session token?

At least 128 bits of real randomness from a cryptographically secure generator. Note that this measures the generator, not the string — a long token from a predictable source is still weak.

Why do malware analysts check entropy?

Packed and encrypted sections have near-maximum entropy while normal code does not, so an entropy graph across a binary shows immediately where the interesting parts are.

Does high entropy mean a string is encrypted?

No. Compressed data, random identifiers and encoded binaries all score high. It means "not ordinary text", which is a much weaker claim.
