# Advanced Terminal Lab

Level up your command line skills.

## Tasks
1. Use grep, awk, and sed to process log files
2. Write a simple bash script that automates a task (e.g., backup or scan)
3. Practice pipes and redirection
4. Use tmux or screen for persistent sessions

## Challenge
Create a custom recon script that combines at least 3 tools and saves output nicely.
