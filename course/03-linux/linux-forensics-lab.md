# Linux Forensics Basics Lab

Learn to investigate a Linux system.

## Tasks
1. Check running processes and network connections
2. Look at user accounts and login history
3. Examine logs in /var/log
4. Find recently modified or suspicious files

## Challenge
Document your findings as if you were responding to a security incident on a Linux server.
