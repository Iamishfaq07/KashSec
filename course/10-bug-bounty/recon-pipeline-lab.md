# Recon Pipeline Lab

Build and run a real reconnaissance pipeline.

## Tools
- subfinder or amass
- httpx
- gau or waybackurls
- nuclei

## Exercise
1. Choose a public bug bounty program in scope
2. Run subdomain enumeration
3. Probe for live hosts
4. Gather URLs and parameters
5. Run nuclei for common vulnerabilities

## Challenge
Document your pipeline, results, and any interesting findings (even if not exploitable).
