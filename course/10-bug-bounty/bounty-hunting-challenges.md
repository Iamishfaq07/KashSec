# Bug Bounty Hunting Challenges

Practical challenges to level up your hunting skills.

## Beginner challenges
1. Find IDOR on a test program
2. Hunt for open redirects
3. Test for XSS in comments

## Tools you should know
- Burp Suite
- Nuclei
- Subfinder

## Challenge
Pick one program on HackerOne or Intigriti and submit at least one valid report this month.
