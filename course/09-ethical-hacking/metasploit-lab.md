# Metasploit Practical Lab

Get comfortable with the most popular exploitation framework.

## Lab setup
Use Metasploitable 2/3 or a vulnerable VM from VulnHub / TryHackMe.

## Tasks
1. Search for exploits using `search`
2. Configure and run an exploit module
3. Get a reverse shell
4. Perform post-exploitation (privilege escalation, credential dumping)

## Challenge
Successfully compromise the target and document the full attack chain with screenshots.
