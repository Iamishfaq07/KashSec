# Reporting Lab

Learn to write professional penetration test reports.

## Tasks
1. Take notes during a lab exploitation (use the Metasploit or recon labs)
2. Write an executive summary
3. Document findings with severity (use CVSS if possible)
4. Provide clear remediation steps
5. Create a sample report in Markdown or Word

## Challenge
Write a full short report for one of the labs you completed earlier and get feedback from someone if possible.
