# SSRF & JWT Lab

Practice two important modern web attacks.

## Lab setup
Use PortSwigger labs or a vulnerable app that has SSRF and JWT endpoints.

## Tasks
1. Exploit an SSRF vulnerability to access internal resources or metadata
2. Analyze a JWT token and tamper with it (alg none, weak secret)
3. Bypass authentication using a modified JWT

## Challenge
Successfully exploit both SSRF and a JWT vulnerability in the lab and document the steps.
