# XSS Practical Lab

Learn to find and exploit Cross-Site Scripting safely.

## Recommended platforms
- PortSwigger Web Security Academy (free labs)
- DVWA (Damn Vulnerable Web Application)

## Tasks
1. Find and exploit a reflected XSS
2. Find and exploit a stored XSS
3. Bypass a simple filter
4. Create a proof-of-concept that shows cookie theft (in a safe lab)

## Challenge
Write a short report for one XSS you found, including impact and how to fix it.
