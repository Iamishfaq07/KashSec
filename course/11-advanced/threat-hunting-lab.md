# Threat Hunting Lab

Learn proactive detection instead of just reacting.

## Lab approach
Use a SIEM-like environment or log files from a lab.

## Tasks
1. Hunt for signs of lateral movement
2. Look for unusual authentication patterns
3. Detect living-off-the-land techniques
4. Create simple detection rules or queries

## Challenge
Write 3 detection hypotheses and validate them against sample data.
