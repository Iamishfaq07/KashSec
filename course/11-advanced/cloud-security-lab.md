# Cloud Security Lab

Get hands-on with common cloud misconfigurations.

## Recommended free labs
- flAWS (AWS)
- TryHackMe Cloud rooms
- HackTheBox Cloud machines

## Tasks
1. Explore IAM policies and find overly permissive roles
2. Access metadata service (IMDS) if vulnerable
3. Identify public S3 buckets or storage
4. Practice basic enumeration of cloud resources

## Challenge
Document at least two cloud misconfigurations you found and how they could be exploited.
