# Containers & Kubernetes Lab

Practice container security basics.

## Lab environment
Use Docker on your Kali VM or online labs.

## Tasks
1. Run a vulnerable container and enumerate it from inside
2. Check for Docker socket exposure
3. Explore Kubernetes RBAC if available in a lab
4. Look for sensitive data in environment variables or secrets

## Challenge
Escalate privileges inside a container or find a misconfiguration and document it.
