# Threat Modeling Lab

Learn to systematically find risks before attackers do.

## Recommended frameworks
STRIDE, PASTA, or Attack Trees.

## Lab exercise
1. Choose a simple application (e.g., a login system or file upload feature)
2. Create a data flow diagram
3. Identify threats using STRIDE
4. Prioritize risks and suggest mitigations

## Challenge
Produce a short threat model document for the chosen feature.
