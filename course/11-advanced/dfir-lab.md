# Digital Forensics & IR Lab

Practice basic incident response and forensics.

## Recommended tools
- Volatility for memory forensics
- Autopsy or The Sleuth Kit for disk analysis
- Sysmon + Elastic or Splunk for log analysis (if available)

## Tasks
1. Analyze a memory dump for suspicious processes
2. Examine a disk image for deleted files or artifacts
3. Review logs to reconstruct a timeline of an incident

## Challenge
Document your findings in an incident report format.
