# Security Scripting Lab

Turn Python into a real security tool.

## Lab tasks
1. Write a script that checks a list of URLs for HTTP status codes
2. Create a simple port scanner using the `socket` module
3. Build a basic password strength checker (expand on the earlier project)
4. Automate a small task with `requests` and `BeautifulSoup` (if installed)

## Challenge
Write a script that takes a domain and outputs open ports + HTTP title for each live host.
