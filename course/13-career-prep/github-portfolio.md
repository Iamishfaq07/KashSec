# Building projects & GitHub portfolio

Projects beat certificates alone.

## Good project ideas
- Custom recon tool or automation script
- Vulnerable app you built and documented exploits for
- Bug bounty write-ups (even if not paid)
- CTF write-ups
- Home lab setup guide (Kali + tools)

## GitHub best practices
- Clean README with screenshots and steps
- Regular commits
- Open source your tools if possible

## Challenge
Create or improve one project this week and push it to GitHub with a great README.
