# Browser DevTools Lab

Learn to use your browser as a hacking tool.

## Tasks
1. Open DevTools (F12) on any website
2. Inspect elements and modify text live
3. Check the Network tab while loading a page
4. Look at Cookies and Storage
5. Use the Console to run simple JavaScript

## Challenge
Find a way to modify a page's content using DevTools and take a screenshot as proof-of-concept.
