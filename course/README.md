# KashSec Academy — The Complete Cybersecurity Course

**Free. From absolute zero to job-ready. Written for people with no prior experience.**

This folder holds the full written course, split into one big file per learning path so each lesson can go as deep as a real textbook chapter. Read them in order — every path builds on the one before it. You never need to buy anything; you'll install free software and practise on free, legal training sites.

---

## How each lesson is structured

Every lesson follows the same friendly, repeatable shape so you always know what to expect:

- **Why this matters** — the point of the lesson before any detail.
- **The core idea, with an everyday analogy** — new concepts explained with things you already understand (post offices, keys, recipes).
- **Deeper detail** — the real substance, built up slowly.
- **Examples, easy → hard** — worked examples and commands you can try.
- **🧪 Lab** — a hands-on exercise to do yourself.
- **🚩 Challenge** — a quick question to test yourself (answer included).
- **Key terms** — a mini-glossary of the new words.
- **Recap** — the lesson in a few bullet points.

> **The golden rule, on every page:** only ever test systems you own or have clear permission to test. Everything here is practised on your own lab or on free, legal training platforms.
