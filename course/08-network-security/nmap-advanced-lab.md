# Advanced Nmap Lab

Master network scanning like a professional.

## Lab environment
Use your own Kali VM or online labs (TryHackMe, HackTheBox Academy).

## Tasks
1. Perform a full TCP connect scan vs SYN scan and compare results
2. Use service version detection (-sV) and OS detection (-O)
3. Run NSE scripts for vulnerability scanning
4. Scan a range of IPs and save output in multiple formats

## Challenge
Write a short report of your scan results including open ports, services, and potential risks.
