# LLM Red Teaming Playbooks

Structured approaches to systematically test LLM applications.

## Building a playbook
- Define scope and success criteria
- Create test cases for each OWASP LLM Top 10 category
- Include both automated and manual tests
- Document bypass techniques and mitigations
- Measure effectiveness over time

## Example structure
1. Recon & mapping the LLM surface
2. Prompt injection campaigns
3. Jailbreak attempts
4. Data extraction tests
5. Agent/tool abuse scenarios

## Challenge
Create a mini playbook with at least 10 test cases for a fictional LLM application that has access to tools.
