# Agentic AI Risks

As AI agents become more powerful, new risks emerge.

## Key concerns
- Agents that can take actions on your behalf (email, code, browsing)
- Prompt injection leading to unintended actions
- Data leakage through long context or tool use
- Lack of oversight and guardrails
- Supply chain attacks on agent frameworks

## Real-world examples
- Agents being tricked into sending emails or running code
- Data exfiltration via clever prompts

Design 5 test cases for an AI agent that can use tools (browser, code execution, email).
