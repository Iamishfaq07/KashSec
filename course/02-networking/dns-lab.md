# DNS Lab

Understand how DNS works and how it can be abused.

## Tasks
1. Use `dig` or `nslookup` to query different record types
2. Find the authoritative nameservers for a domain
3. Look up historical DNS data (using tools like SecurityTrails or viewdns.info)
4. Identify potential DNS misconfigurations or interesting records

## Challenge
Map the DNS infrastructure of a target and note any interesting findings.
