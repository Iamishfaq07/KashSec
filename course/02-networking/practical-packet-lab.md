# Practical Packet Analysis Intro

See how data actually moves.

## Simple exercise
1. Install Wireshark (or use an online packet capture)
2. Capture traffic while visiting a website
3. Find the HTTP/HTTPS requests and responses
4. Identify source and destination IPs and ports

## What to look for
- TCP handshake (SYN, SYN-ACK, ACK)
- DNS queries
- Data being sent in cleartext (if any)

## Challenge
Capture 10 packets and label what each one is doing.
