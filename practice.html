Practice tasks

Type the answer, don't pick it. 104 hands-on practice tasks across 26 paths — subnetting, Linux commands, CVSS scoring, log reading, web and cloud security. Free, no account, answers checked in your browser.

Every task asks you to produce an answer rather than recognise one among four options — compute a subnet, write the command, read the output and name the flaw. Answers are verified in your browser against a stored hash, so nothing you type is sent anywhere and the answers are not readable in the page.

  • A site shows a padlock and a valid certificate. Which one of these does that actually prove?
  • A flaw is published on Monday and patched the same day. Attackers start exploiting unpatched machines on Tuesday. What is the general name for an attack against a flaw that has a patch available but not yet applied? (two words)
