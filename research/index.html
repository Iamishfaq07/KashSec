Research vault

These cards either link out or tell an original fictional case. KashSec does not copy paid writeups or exam material. A card marked “not re-fetched” still needs you to open the source.

OWASP API Security Top 10 (Curated external link). The project page describes API-specific risks for people who build and test APIs. Use it as the external source of the category names, then practise the invoice case here. OWASP Application Security Verification Standard (Curated external link). ASVS is a verification catalogue, not a scanner result. Use the project page to see how requirements are grouped, then map one KashSec lab to a requirement in your own words. PortSwigger Web Security Academy (Curated external link). A free web-security course with its own labs. KashSec links to it for HTTP and access-control practice that this site does not try to duplicate. MITRE ATT&CK (Curated external link). A public catalogue of adversary tactics and techniques. Use a technique as a question about logs, not as proof that the technique happened in your environment. NIST Cybersecurity Framework (Curated external link). NIST’s framework page for talking about cybersecurity outcomes with people who do not want a tool tour. The page identified CSF 2.0 on 18 Nov 2026. CISA cybersecurity advisories (Curated external link). A public list of advisories. Practise reading one advisory for affected products and the required action, then stop. Do not scan the internet to “see if it is true.” OWASP Top 10 for Large Language Model Applications (Curated external link). A project page for risks that show up when an application trusts model output. Read it next to the KashSec agent-boundary lab, which is a simulation. Case: the invoice that trusted the query string (Original KashSec study). A fictional billing API returned invoice 42 from another company because the handler preferred the tenant in the query string over the tenant in the session. Case: the assistant that tried a second tool (Original KashSec study). A fictional assistant was allowed to read one invoice. Text in the retrieved document asked it to send a different invoice and to treat its own “approved” flag as permission. Case: Northbridge Billing, one invoice and three jobs (Original KashSec study). The same fictional invoice bug, seen by a tester, an AppSec engineer, and a SOC analyst. No system outside this browser is involved. Case: the billing role that could do anything (Original KashSec study). Northbridge’s fictional billing function started with a role that allowed every action, in every tenant, for every principal. The cloud desk asks you to shrink it. Kubernetes Pod Security Standards (Curated external link). Kubernetes documents three pod security profiles: privileged, baseline, and restricted. The practice lab is a smaller fixture, not that policy engine. Secure use of GitHub Actions (Curated external link). GitHub’s current secure-use page covers untrusted code from pull requests, token permissions, and pinning actions. The old hardening-guide URL redirected here on the check date. OWASP Authorization Cheat Sheet (Curated external link). A short OWASP page on denying by default and checking authorization on the server for each object and function. RFC 6749: The OAuth 2.0 Authorization Framework (Curated external link). The OAuth 2.0 spec. The practice debugger checks state, redirect, and scope behavior. It is not an implementation of the RFC, and OAuth is not the same thing as a JWT. RFC 9110: HTTP Semantics (Curated external link). The current HTTP semantics spec, including what status codes mean. The inspector lab uses only 200, 401, 403, and 404. OWASP Top Ten (Curated external link). OWASP’s Top Ten project index. Confirm the edition on the page. The older project path redirected here on 18 Nov 2026. OWASP Web Security Testing Guide (Curated external link). OWASP’s Web Security Testing Guide project. Use it as a method list for authorised tests. It is not a list of targets. The older project path redirected here on 18 Nov 2026. Kusto Query Language documentation (Curated external link). Microsoft’s Kusto language reference. The Northbridge filter is a few dropdowns, not KQL, and this page is not the SC-200 exam.
