# KashSec preview academy

A separate app for the same curriculum: 26 paths, 485 lessons, quizzes, glossary, labs, and browser tools.

It does not replace the static site at the repository root. Merging this branch only adds the `preview/` directory.

```bash
cd preview
npm install
npm run dev
```

Progress, notes, and bookmarks stay in the browser. Nothing is sent to a server.
