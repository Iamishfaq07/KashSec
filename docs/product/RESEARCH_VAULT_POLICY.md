# Research vault policy

## Kinds

- `curated-external` — title, summary, and link. The source text is not stored.
- `original-kashsec` — fictional cases written for KashSec.
- Permissioned republish, student submission, and interactive reconstruction are reserved and unused.

## What was fetched on 18 Nov 2026

OWASP API Security project, PortSwigger Web Security Academy, MITRE ATT&CK, NIST CSF (the page named CSF 2.0), CompTIA Security+ V7/V8, the OSCP+ exam guide, and the SC-200 certification page.

Cards with `checked: null` (ASVS project, CISA advisory index, OWASP LLM project) are labeled “not re-fetched” in the UI. Do not treat those summaries as a fresh page review.

## Not allowed

- Pasting copyrighted writeups, exam questions, or active-CTF spoilers.
- Public student HTML uploads. There is no submission form in this release.
- A takedown mailbox is the existing contact page (`/contact.html`). This change does not add a separate queue.
