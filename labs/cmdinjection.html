Command Injection Sandbox

A "ping this host" tool glues your input into a real shell command. Chain a second command onto the intended one.

A "ping this host" feature that builds a shell command by pasting your input into a string. Add a shell metacharacter and your second command runs alongside the first — with whatever privileges the web process holds.

How to use it

  1. Ping a normal hostname.
  2. Append a shell separator such as ; or &&.
  3. Run a command the feature never intended.

What to take away

The shell is the problem

Invoking a command through a shell means metacharacters are interpreted. Passing an argument array directly to the process avoids the shell entirely.

Blind command injection is common

When output is not returned, attackers confirm execution with timing — sleep 10 — or an outbound network callback.

Frequently asked questions

How is command injection fixed?

Do not build shell strings from input. Use APIs that take an argument array, avoid shell invocation, and where a value must be user-supplied, allowlist its format strictly.

Which characters matter?

; && || | & newline, plus $() and backticks for substitution. Any one of them can extend the intended command.
