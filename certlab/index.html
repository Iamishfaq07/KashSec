Certification prep

Prepare for CompTIA Security+, OffSec OSCP+, or Microsoft SC-200 without leaving the course. Each plan uses lessons and labs that already exist, plus a short formative check. Passing a check is not an official score.

CompTIA Security+. Two versions can overlap. Confirm which code you will sit before you book. SY0-801: CompTIA’s V8 page lists exam code SY0-801, English at launch, up to 90 multiple-choice and performance-based questions, 90 minutes, and a passing score of 750 on a 100–900 scale. Checked 18 Nov 2026. SY0-701: CompTIA’s V7 page lists retirement of the English exam on 11 June 2027, and Japanese, Portuguese, Spanish, and Thai on 13 August 2027. Same question cap, time, and passing score. Checked 18 Nov 2026. Objectives in this starter plan: Name the goal a control protects (30 min), Separate a real technique from a product name (40 min), Put the authorization check on the server (45 min), Triage evidence before you escalate (40 min), Say what a policy does not prove (25 min). KashSec estimated readiness is not a CompTIA pass prediction, and these questions are not from any CompTIA exam bank. OffSec OSCP+. This is a lab-and-report exam. A multiple-choice quiz is not a substitute. OSCP+: The exam guide checked 18 Nov 2026 says you have 23 hours and 45 minutes. The published structure is 3 stand-alone machines (60 points) and one Active Directory set of 3 machines (40 points). A professional PDF report is required. Exams starting on or after 1 December 2026 at 08:00 GMT use scaled scoring. KashSec does not know your exam set’s scaled cutoff. Objectives in this starter plan: Write down what a service claims before you touch it (40 min), Treat object access as a separate bug from login (50 min), Make a finding reproducible (45 min), Stop at the boundary you were given (20 min). Nothing here is an OffSec lab, an exam machine, or a guarantee you will pass. Practise only on systems you are allowed to test. Microsoft Security Operations Analyst (SC-200). Conceptual practice only. A real Sentinel or Defender tenant is a separate, optional lab. SC-200: The English certification page, last updated 21 Oct 2026 and re-checked 18 Nov 2026, lists three assessed areas: manage a security operations environment, respond to security incidents, and perform threat hunting. It states a 100-minute assessment and a 12-month renewal. It does not show domain percentages or a question count on that page, so KashSec does not invent them. Objectives in this starter plan: Know which tool would answer the question (30 min), Decide true positive, false positive, or needs data (40 min), Turn a technique name into a question about your logs (35 min). These exercises use synthetic logs. They are not Microsoft KQL, not a scoring engine for SC-200, and not evidence that a production tenant is secure.
